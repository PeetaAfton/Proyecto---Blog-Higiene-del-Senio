# Idea principal
Proyecto para la creación de un blog informativo sobre la higiene del sueño dirigido principalmente para niños y sus padres.

# Consigna
El desarrollo de sitios web es una competencia clave en la era digital. Su fundamento es el Lenguaje de Marcado de Hipertexto (HTML), que actúa como esqueleto estructural de cada página; combinado con las Hojas de Estilo en Cascada (CSS, Cascading Style Sheets) y JavaScript, forma la tríada tecnológica que hace posible la web contemporánea.

En este proyecto se aplican los conocimientos de diseño de un sitio web para crear, mediante una plataforma gratuita, un recurso educativo en línea sobre un tema específico. El sitio web deberá integrar texto, imágenes y contenidos multimedia de manera organizada y atractiva.

## Etapas de desarrollo
1. Redactar un resumen introductorio conciso, estructurar el cuerpo en secciones con subtítulos coherentes e incluir al menos tres recursos multimedia: imágenes pertinentes, un video incrustado (YouTube u otra plataforma) y un audio, presentación embebida o animación que enriquezca la comprensión.
2. Construir el sitio web con las etiquetas esenciales de HTML (, , , , entre otros), usar encabezados, párrafos, listas y enlaces internos y externos, y aplicar estilos básicos en CSS para mejorar la legibilidad y la estética.
3. Documentar el proyecto: registrar la justificación pedagógica, el diseño visual y la selección de recursos multimedia para incluirlos en el informe PDF.
4. La versión final del sitio web debe publicarse en una plataforma en línea gratuita. Una vez habilitado el acceso público mediante un enlace, este enlace debe incluirse tanto en la portada del documento como en la sección “Desarrollo”.
